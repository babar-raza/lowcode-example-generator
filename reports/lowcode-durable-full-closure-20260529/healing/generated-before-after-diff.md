## diagram-diagram-converter

```csharp

shape.ID = 1;
```

### AFTER (new deterministic template — FIXED)
```csharp

if (shape != null)
{

    shape.XForm.PinX.Value = 2.0;  // DoubleValue.Value
    shape.XForm.PinY.Value = 2.0;
}
```
Build: SUCCESS (1 obsolete warning for DrawEllipse, 0 errors)
