# Aspose.Finance - Convert Xbrl

Convert XBRL data using Aspose.Finance

## Prerequisites

- .NET 8.0 SDK or later
- NuGet package: `Aspose.Finance`

## How to Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Output

The program produces output files in the current directory.
