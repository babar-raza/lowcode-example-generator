# Discovery: Example-Reviewer Fixture System

## Overview

The example-reviewer repository includes a fixture system that generates input files for C# example validation. This document records the discovery findings from Step 1 of the Fixture Strategy and Self-Contained Example Healing Sprint.

## Reuse Mode

The fixture system uses `copy` mode: fixtures generated by the factory are copied into the target project directory before build/run.

## Fixture Builders Found

The following fixture builders were discovered in the example-reviewer fixture system:

- `generate_xlsx` — generates `.xlsx` workbook files via `openpyxl`
- `generate_csv` — generates `.csv` tabular data files
- `generate_txt` — generates `.txt` plain-text files
- `generate_json` — generates `.json` structured data files
- `generate_html` — generates `.html` markup files
- `generate_docx` — generates `.docx` Word document files via `python-docx`

## Supported Formats

| Format | Builder | Notes |
|--------|---------|-------|
| `xlsx` | `generate_xlsx` | Workbook with sample data |
| `csv` | `generate_csv` | Tabular data |
| `txt` | `generate_txt` | Plain text |
| `json` | `generate_json` | Structured JSON |
| `html` | `generate_html` | HTML markup |
| `docx` | `generate_docx` | Word document |
