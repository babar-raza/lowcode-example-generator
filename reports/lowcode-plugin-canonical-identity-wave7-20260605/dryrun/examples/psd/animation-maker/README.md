# .NET Animation Maker

This example demonstrates the **.NET Animation Maker** for .NET.

Canonical product page: [https://products.aspose.net/psd/animation-maker/](https://products.aspose.net/psd/animation-maker/)

## What It Does

Creates a multi-frame GIF animation from PSD layers using Aspose.PSD TimeLine API. Demonstrates programmatic animation creation with loop control.

## How to Run

```bash
dotnet run
```

## Output

Animated GIF written to `output/animation.gif`.
