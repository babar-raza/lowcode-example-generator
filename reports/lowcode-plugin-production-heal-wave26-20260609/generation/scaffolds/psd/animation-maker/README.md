# Aspose.Psd - Animation Maker

Create PSD animations using Aspose.PSD

## Prerequisites

- .NET 8.0 SDK or later
- NuGet package: `Aspose.PSD`

## How to Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Output

The program produces output files in the current directory.
