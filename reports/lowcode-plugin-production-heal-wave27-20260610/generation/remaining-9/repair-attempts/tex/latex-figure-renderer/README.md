# Aspose.Tex - Latex Figure Renderer

Render LaTeX figures using Aspose.TeX

## Prerequisites

- .NET 8.0 SDK or later
- NuGet package: `Aspose.TeX`

## How to Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Output

The program produces output files in the current directory.
