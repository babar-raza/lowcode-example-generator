# pdf-jpeg

Auto-generated example for **Aspose.PDF** (net8.0).

## API Symbols Used

`Aspose.Pdf.LowCode.Jpeg`

## Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Input and Output

The example takes a PDF file (`input.pdf`) as input.
The converted JPEG images are saved as `.jpg` files.
