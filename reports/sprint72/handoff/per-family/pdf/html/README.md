# pdf-html

Auto-generated example for **Aspose.PDF** (net8.0).

## API Symbols Used

`Aspose.Pdf.LowCode.Html`, `Aspose.Pdf.LowCode.Html.Dispose`, `Aspose.Pdf.LowCode.Html.Process`

## Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Input and Output

The example takes an HTML file (`input.html`) as input.
The converted PDF document is saved as `output.pdf`.
