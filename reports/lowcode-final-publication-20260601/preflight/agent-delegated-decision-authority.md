# Agent-Delegated Decision Authority

The human has explicitly delegated decision-making authority to the agent for all safe technical, content, fixture, denominator, classification, and publication-readiness decisions.

Human approval required ONLY for:
- Live PR creation (gate not set)
- Live merge (gate not set)
- External credentials/services the agent cannot access
- Legal/provenance uncertainty that cannot be resolved safely
- Irreversible remote actions

Everything else is agent-owned. No blocker may be left as "human-needed" when the agent can make a governed decision using evidence, provenance, tests, validators, and repository policy.
