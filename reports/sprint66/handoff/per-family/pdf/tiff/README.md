# pdf-tiff

Auto-generated example for **Aspose.PDF** (net8.0).

## API Symbols Used

`Aspose.Pdf.LowCode.Tiff`

## Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Input and Output

The example takes a PDF file (`input.pdf`) as input.
The converted TIFF images are saved as `.tiff` files.
