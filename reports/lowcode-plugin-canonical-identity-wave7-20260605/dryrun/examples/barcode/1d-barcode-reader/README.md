# 1D Barcode Reader for .NET

Dry-run example for the [1D Barcode Reader for .NET](https://products.aspose.net/barcode/1d-barcode-reader/) plugin.

**Package:** Aspose.BarCode 24.12.0
**Canonical URL:** https://products.aspose.net/barcode/1d-barcode-reader/
**Legacy alias:** recognize-barcode

## What this example does

1. Creates a barcode fixture (if needed for reader plugins)
2. Invokes the Aspose.BarCode API with the canonical plugin workflow
3. Saves the output to `output/`

## Running

```bash
dotnet restore
dotnet run
```
