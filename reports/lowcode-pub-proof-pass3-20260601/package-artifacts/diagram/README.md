## Overview

This repository contains verified C# examples for the **Aspose.Diagram for .NET LowCode API** — a set of
high-level classes in the `Aspose.Diagram.LowCode` namespace that perform common
diagram-processing operations in a single method call.

Each example is generated by the lowcode-example-generator pipeline, validated through
dotnet build + runtime execution + output verification.

---

## Examples

### DiagramConverter

Convert Visio diagrams between formats.

**Location**: `examples/diagram/lowcode/diagram-converter/`

```csharp
DiagramConverter.Process("input.vsdx", "output.vdx");
```

### PdfConverter

Convert Visio diagrams to PDF.

**Location**: `examples/diagram/lowcode/pdf-converter/`

```csharp
PdfConverter.Process("input.vsdx", "output.pdf");
```
