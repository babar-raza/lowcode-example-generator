Auto-generated example for **Aspose.Words** (net8.0).

`Aspose.Words.LowCode.Converter`, `Aspose.Words.LowCode.Converter.Convert`

## Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Input and Output

The example takes a Word document file (`input.docx`) as input.
The converted PDF document is saved as `output.pdf`.
