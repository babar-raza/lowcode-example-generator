# PSD Photo Processor for .NET

This example demonstrates the **.NET PSD Photo Processor** for .NET.

Canonical product page: [https://products.aspose.net/psd/photo-processor/](https://products.aspose.net/psd/photo-processor/)

## What It Does

Processes a PSD photo: loads the image, resizes it, and exports as JPEG. Demonstrates batch-capable photo processing with Aspose.PSD.

## How to Run

```bash
dotnet run
```

## Output

Processed JPEG written to `output/processed.jpg`.
