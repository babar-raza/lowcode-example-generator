# Aspose.Html - Html To Docx Converter

Convert HTML to DOCX using Aspose.HTML

## Prerequisites

- .NET 8.0 SDK or later
- NuGet package: `Aspose.HTML`

## How to Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Output

The program produces output files in the current directory.
