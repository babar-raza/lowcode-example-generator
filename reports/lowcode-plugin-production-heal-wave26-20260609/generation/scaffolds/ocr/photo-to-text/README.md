# Aspose.Ocr - Photo To Text

Use Aspose.Ocr Photo To Text

## Prerequisites

- .NET 8.0 SDK or later
- NuGet package: `Aspose.OCR`

## How to Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Output

The program produces output files in the current directory.
