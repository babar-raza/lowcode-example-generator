# Aspose.Tasks - Project To Pdf Converter

Convert project files to PDF using Aspose.Tasks

## Prerequisites

- .NET 8.0 SDK or later
- NuGet package: `Aspose.Tasks`

## How to Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Output

The program produces output files in the current directory.
