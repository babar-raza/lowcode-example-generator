# pdf-toc-generator

Auto-generated example for **Aspose.PDF** (net8.0).

## API Symbols Used

`Aspose.Pdf.LowCode.TocGenerator`, `Aspose.Pdf.LowCode.TocGenerator.Dispose`, `Aspose.Pdf.LowCode.TocGenerator.Process`

## Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Input and Output

The example takes a PDF file (`input.pdf`) as input.
The PDF with a generated table of contents is saved as `output.pdf`.
