# Final ZIP Validation Companion-Proof Design

## Problem
Including validation proof inside ZIP changes the ZIP hash → circular dependency.

## Solution: Companion Proof
Validation proof written as `<zip>.validation.json` next to the ZIP.

## Guarantees
1. Companion proof names exact ZIP path
2. Contains ZIP SHA256 computed after ZIP is finalized
3. ZIP hash is stable — no post-creation modifications
4. Generated by `generate_companion_proof()` → `generate_validation_proof()`

## Implementation
```python
from plugin_examples.evidence_contract import generate_companion_proof

proof = generate_companion_proof("path/to/bundle.zip")
# Writes: path/to/bundle.zip.validation.json
```
