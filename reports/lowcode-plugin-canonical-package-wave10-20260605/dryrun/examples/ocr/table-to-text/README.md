# Table to Text Converter for .NET

This example demonstrates the **.NET Table to Text Extractor** for .NET.

Canonical product page: [https://products.aspose.net/ocr/table-to-text/](https://products.aspose.net/ocr/table-to-text/)

## What It Does

Extracts tabular text from an image using Aspose.OCR with TABLE area detection mode. Identifies table structures and extracts text cell-by-cell.

## How to Run

```bash
dotnet run
```

## Output

Recognized table text written to `output/table-text.txt`.
