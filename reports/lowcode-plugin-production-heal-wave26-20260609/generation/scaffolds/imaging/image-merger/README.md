# Aspose.Imaging - Image Merger

Merge multiple images using Aspose.Imaging

## Prerequisites

- .NET 8.0 SDK or later
- NuGet package: `Aspose.Imaging`

## How to Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Output

The program produces output files in the current directory.
