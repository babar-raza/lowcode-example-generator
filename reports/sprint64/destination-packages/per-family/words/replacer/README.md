# words-replacer

Auto-generated example for **Aspose.Words** (net8.0).

## API Symbols Used

`Aspose.Words.LowCode.Replacer`, `Aspose.Words.LowCode.Replacer.Replace`

## Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Input and Output

The example takes a Word document file (`input.docx`) as input.
The document with text replacements is saved as `output.docx`.
