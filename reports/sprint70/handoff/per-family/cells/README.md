## Overview

This repository contains verified C# examples for the **Aspose.Cells for .NET LowCode API** — a set of
high-level classes in the `Aspose.Cells.LowCode` namespace that perform common
document-processing operations in a single method call.

Each example is generated by the [lowcode-example-generator](https://github.com/babar-raza/lowcode-example-generator)
pipeline, validated through dotnet build + runtime execution + output verification, and published
here as a repeatable reference.

| `spreadsheet-locker` | `SpreadsheetLocker.Process` | `xlsx` | `xlsx` | `dotnet run --project examples/cells/lowcode/spreadsheet-locker` |
| `spreadsheet-merger` | `SpreadsheetMerger.Process` | `xlsx (×N)` | `xlsx` | `dotnet run --project examples/cells/lowcode/spreadsheet-merger` |
| `spreadsheet-splitter` | `SpreadsheetSplitter.Process` | `xlsx` | `xlsx (×N)` | `dotnet run --project examples/cells/lowcode/spreadsheet-splitter` |
| `text-converter` | `TextConverter.Process` | `csv` | `txt` | `dotnet run --project examples/cells/lowcode/text-converter` |

> **Cardinality key:** `×N` in the Input column means the operation merges N input files into one.
> `×N` in the Output column means the operation splits or extracts into N output files.
> `2×` prefix means exactly two inputs are required.

<summary><code>spreadsheet-merger/Program.cs</code></summary>

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.LowCode;

class Program
{
    static void Main()
    {
        // Prepare a simple input workbook if it does not already exist
        string inputPath = Path.Combine(AppContext.BaseDirectory, "input.xlsx");
        if (!File.Exists(inputPath))
        {
            var workbook = new Workbook();
            workbook.Worksheets[0].Name = "Sheet1";
            workbook.Save(inputPath);
        }

        // Validate input file exists
        if (!File.Exists(inputPath))
            throw new FileNotFoundException("Input file not found.", inputPath);

        // Define output file path
        string outputPath = Path.Combine(AppContext.BaseDirectory, "output.xlsx");

        // Use the overload of SpreadsheetMerger.Process that accepts an array of template files
        SpreadsheetMerger.Process(new[] { inputPath }, outputPath);

        // Validate output file was created
        if (!File.Exists(outputPath))
            throw new InvalidOperationException("Output file was not created by SpreadsheetMerger.Process.");

        // Deterministic success output
        Console.WriteLine($"SpreadsheetMerger.Process succeeded: {outputPath} ({new FileInfo(outputPath).Length} bytes)");
    }
}
```

## How to Run

Clone the repository and run any example:

```bash
git clone https://github.com/aspose-cells-net/Aspose.Cells.LowCode-for-.NET-Examples.git
cd Aspose.Cells.LowCode-for-.NET-Examples

# Restore all packages
dotnet restore

# Run a specific example (replace <example-name> with any name from the table above)
dotnet run --project examples/cells/lowcode/<example-name>
```

Each example is a self-contained .NET project. Running it produces an output file in the project
directory (e.g., `output.csv`, `output.html`, `output.json`, `output.pdf`, `output.png`, `output.txt`, `output.xlsx`).
