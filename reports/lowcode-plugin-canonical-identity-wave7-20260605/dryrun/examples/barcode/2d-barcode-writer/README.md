# 2D Barcode Writer for .NET

Dry-run example for the [2D Barcode Writer for .NET](https://products.aspose.net/barcode/2d-barcode-writer/) plugin.

**Package:** Aspose.BarCode 24.12.0
**Canonical URL:** https://products.aspose.net/barcode/2d-barcode-writer/
**Legacy alias:** generate-qr-code

## What this example does

1. Creates a barcode fixture (if needed for reader plugins)
2. Invokes the Aspose.BarCode API with the canonical plugin workflow
3. Saves the output to `output/`

## Running

```bash
dotnet restore
dotnet run
```
