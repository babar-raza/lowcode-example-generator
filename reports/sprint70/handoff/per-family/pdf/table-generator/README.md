# pdf-table-generator

Auto-generated example for **Aspose.PDF** (net8.0).

## API Symbols Used

`Aspose.Pdf.LowCode.TableGenerator`, `Aspose.Pdf.LowCode.TableGenerator.Dispose`, `Aspose.Pdf.LowCode.TableGenerator.Process`

## Run

```bash
dotnet restore
dotnet build
dotnet run
```

## Input and Output

The example takes a PDF file (`input.pdf`) as input.
The PDF with generated tables is saved as `output.pdf`.
