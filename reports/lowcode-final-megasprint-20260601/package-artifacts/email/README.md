## Overview

This repository contains verified C# examples for the **Aspose.Email for .NET LowCode API** — a set of
high-level classes in the `Aspose.Email.LowCode` namespace that perform common
email-processing operations in a single method call.

Each example is generated by the lowcode-example-generator pipeline, validated through
dotnet build + runtime execution + output verification.

---

## Examples

### Converter

Convert email messages (EML) to HTML using the async LowCode Converter API.

**Location**: `examples/email/lowcode/email-converter/`

```csharp
using var stream = new MemoryStream(File.ReadAllBytes("input.eml"));
var outputHandler = new FolderOutputHandler("output_html");
await Converter.ConvertToHtml(stream, "input.eml", outputHandler);
```
